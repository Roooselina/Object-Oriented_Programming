# 객체지향 프로그래밍 (C++)

객체지향 프로그래밍 강의와 LAB의 주차별 실습, 중간·기말 대체 과제 백업입니다. Visual Studio 프로젝트 형태입니다.

| 폴더 | 내용 |
|---|---|
| `객체 지향 프로그래밍/` | 주차별 실습: 참조와 포인터, 클래스, 디폴트 인수, hangman, tower 실습, 주사위(die), array와 vector, 키오스크 알고리즘 등 |
| `객체 지향 프로그래밍 lab 중간 대체 과제/` | 학생 정보 관리 (`Student`, `StudentInfo`) |
| `객체 지향 프로그래밍 lab 기말 대체 과제/` | 기말 대체 과제 (`MAIN.cpp`) |
| `기말 객체지향 프로그래밍 과제/` | 던전 게임 (`Deongeon game.cpp`) |

- `객체 지향 프로그래밍/기말_5주차 수업_lab/SFML/`에는 외부 라이브러리 SFML의 헤더와 문서(약 1,000개 파일)가 포함되어 있습니다. SFML은 zlib/png 라이선스를 따르는 외부 라이브러리이며 직접 작성한 코드가 아닙니다.
- `x64/`, `Debug/`, `.vs/` 등 빌드 산출물과 `.exe`가 함께 커밋되어 있습니다.
